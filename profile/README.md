## 🎲 공정한 추첨

경품 추첨 웹앱은 참가자 목록을 고정한 뒤 seed를 만들고, **SHA-256 기반의 재현 가능한 알고리즘**으로 당첨자를 뽑습니다.
같은 참가자 목록과 seed가 있으면 누구나 같은 결과를 다시 얻을 수 있습니다.
